# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-confirmed: static HTML/CSS/JavaScript behind the owner's existing NGINX; a Node.js synchronization job generates the site. This follows the existing homepage's static hosting. No standing build-path preference has been recorded.

## Users

People exploring the owner's public AI skills and choosing how to use them. The recent instruction to explain installation to nontechnical readers informs the initial copy; this audience emphasis is an inference from the same conversation.

## Product Purpose

Mirror the owner's GitHub-published public skills automatically at skills.itops.dev. Visitors should understand a skill, start using it, download its files, and reach its GitHub source.

## Operating Context

The owner publishes public skills to `yetanotherrepo` on GitHub. The initial verified publication is `future-letter`. The website must pick up new publications and updates. Local installed skills are not all approved for publication.

## Capabilities and Constraints

Public-only source discovery, catalog, individual skill pages, original instruction text, downloadable packages, and source attribution. No execution of skill content during mirroring. User-confirmed scope: include owned public repositories and public forks. Static publication is isolated from the existing homepage.

## Brand Commitments

The user explicitly requires the style of itops.dev and application of Kovodstvo and Impeccable. The existing homepage is the visual authority. Preserve its recognizable terminal identity and keep installation language understandable.

## Evidence on Hand

Live itops.dev HTML and visual inspection on 2026-10-27; live public GitHub source for future-letter. No invented catalog entries, usage statistics, testimonials, or claimed user tests.

## Product Principles

- GitHub is the publication source; the mirror is a readable, usable copy.
- Explain what a visitor can do in plain language.
- Preserve the original skill and its supporting files as data.
- Report source and update state honestly.
