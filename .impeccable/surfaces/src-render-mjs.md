# Catalog and skill pages

Mode: Read. The visitor wants to find a useful skill, understand its purpose, and obtain instructions or an installable copy. Catalog and detail pages share the existing itops.dev visual identity.

## Direction contract

THESIS: a readable public directory in the owner's terminal world; the actual published skill leads, with no invented showcase entries or dashboard statistics.

OWN-WORLD: black background, vivid green headings and interaction, Courier-style monospaced type, quiet green-tinted body text, square controls, and one restrained terminal cursor. The homepage's exact green remains the anchor. Dense instruction pages temper glow for reading.

STORY: understand what skills are, choose a real entry, then copy a ready-to-send request or download the original bundle; source and freshness remain visible.

FIRST VIEWPORT: a compact site/source navigation, a large two-line green heading on the left, short introductory copy, then a full-width searchable directory with a real skill row. Detail pages place the title and purpose before explicit copy/download actions; original instructions follow as a readable disclosure.

FORM: existing-world extension with a precisely scoped catalog/detail task. No new visual-world seed; the user's live itops.dev reference fixes the visual system. The user confirmed a code-led build and a static site on the VPS. No standing default was saved. Signature interaction: filtering the directory and immediate, truthful copy confirmation, with a small cursor as the single motion motif.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Quality bar: original itops.dev establishes recognition, while instruction layout must support long Russian paragraphs, keyboard navigation, copy failure, and a 390px viewport. No shipping raster is required.
